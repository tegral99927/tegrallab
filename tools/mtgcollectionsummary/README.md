# MTGCollectionSummary

Magic: The Gathering（MTG）のコレクション管理とデッキ構築を統合した完全ローカルWebアプリケーションです。

ブラウザの IndexedDB を活用し、サーバー不要・会員登録不要・完全無料ですべてのデータを手元の端末に安全に保存しながら、Scryfall APIと連携して最新の日本語/英語カード情報をシームレスに利用できます。

---

## 🌟 主な機能

### 1. コレクション管理
- **詳細なカード記録**: 枚数、エキスパンション、コレクター番号、言語、Foil/通常、コンディション（NM/SP/MP/HP/D）、購入価格、入手日、保管場所（バインダー・デッキケース等）、自由タグ、メモ。
- **別版・同名カードの厳密管理**: 同名カードでもエキスパンションや言語、Foilなどの仕様違いを正確に別個体/ロットとして管理。
- **一括操作**: 複数カードの選択、一括削除、一括保管場所移動、一括タグ付け。
- **コレクション統計分析**: 総所有枚数、ユニークカード数、推定総資産価値（USD/JPY）、高額所有カードランキング、重複所有カードの自動検出。

### 2. デッキビルダー & 統率者（EDH）特化機能
- **対応フォーマット**: コマンダー (EDH)、パウパーEDH、ブロール、スタンダード、パイオニア、モダン、レガシー、ヴィンテージ、パウパー、ヒストリック、エクスプローラー、アルケミー、タイムレス、カジュアル。
- **ルール・整合性バリデーション**: デッキ枚数、ハイランダー制限、4枚制限、禁止制限カード判定。
- **高度な統率者サポート**:
  - 伝説のクリーチャーおよび統率者指定能力を持つプレインズウォーカー等の適格性判定。
  - 共闘（Partner）、特定の組み合わせ（Partner with...）、背景選択（Choose a Background）、ずっと友達（Friends forever）、ドクターのコンパニオン（Doctor's companion）等の複数統率者ルール判定。
  - 統率者の固有色（Color Identity）自動計算およびデッキ内カードの固有色違反チェック。
  - 統率者を含めた100枚チェック。
- **EDHブラケット設定**: ブラケット 1〜5 の設定および Game Changers（強力 staple 群）の自動検出と採用数表示。
- **カードの役割分類**: ランプ、ドロー、サーチ、単体除去、全体除去、打ち消し、墓地対策、防護、コンボ、フィニッシャー、土地など自由なタグ付け。

### 3. コレクションとデッキの連携・競合分析
- **所持状況の照合**: デッキに必要なカードとコレクションの所持枚数を即座に照合（所有率%、不足枚数リスト表示）。
- **複数デッキ同時構築の競合分析**: 同時に組みたい複数のデッキを選択し、コレクションの所有枚数と突き合わせて重複利用による物理的不足枚数を一括算出。
- **ウィッシュリスト自動連携**: デッキの不足カードを1クリックでウィッシュリストへ一括登録。

### 4. 高度な統計・分析 & 初手シミュレーター
- **SVGグラフ可視化**: 外部ライブラリ非依存の軽量SVGマナカーブ、色別分布、カードタイプ内訳。
- **超幾何分布（Hypergeometric Distribution）計算**: 
  - 初手7枚における土地枚数の確率分布表。
  - 指定ターンまでに特定カードを引く累積確率。
- **初手シミュレーター**: 実デッキからの7枚ドロー、ロンドンマリガン、ターン進行ドロー、ライブラリー残枚数管理。
- **サマリー出力**: テキストコピー、TXT保存、CSV、JSON、印刷用レイアウト（Print/PDF）。

### 5. 高性能インポート & エクスポート
- **対応形式**: MTG Arena（日本語・英語）、晴れる屋互換Arenaテキスト、Magic Online（.dec / SB:）、通常テキスト（枚数＋カード名）、CSV、JSON。
- **インポートプレビュー**: 取り込み前に認識できたカードと未認識カードを一覧表示し、確認した上で新規デッキまたは既存デッキへ反映。
- **エクスポート**: 言語選択（日本語/英語）、ソート順（タイプ/CMC/名前/枚数）、セット番号表示の切り替え、1クリックコピー＆ファイルダウンロード。

### 6. デッキバージョン管理 & 比較
- **スナップショット保存**: デッキの任意の変更段階をスナップショットとして保存し、いつでも復元可能。
- **デッキ比較**: 2つのデッキを選択し、共通カード、各固有カード、平均CMC差、土地枚数差、推定価格差を一覧比較。

## 🚀 起動方法

本アプリケーションはビルド作業やパッケージインストール（npm install等）を一切必要としません。Vanilla HTML/CSS/JavaScript のみで構成されているため、ダウンロードしてそのまま利用できます。

### 推奨実行環境
- **対応ブラウザ**: Google Chrome、Microsoft Edge、Mozilla Firefox、Apple Safari（最新版）
- **通信環境**: 初回起動およびカード検索・価格取得時はインターネット接続が必要です。既に取得してIndexedDBに保存されたデータはオフラインでも閲覧・編集可能です。

### ローカルでの起動方法
ブラウザのセキュリティポリシー（IndexedDBやFetch API）を確実に動作させるため、ローカルWebサーバーでの起動を推奨します。

#### 方法1: VS Code Live Server
1. VS Codeで `tools/mtgcollectionsummary` フォルダを開きます。
2. `index.html` を右クリックして「Open with Live Server」を選択します。

#### 方法2: Python 簡易サーバー
ターミナルまたはPowerShellで以下を実行します：
```bash
cd tools/mtgcollectionsummary
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。

#### 方法3: Node.js 簡易サーバー
```bash
npx serve tools/mtgcollectionsummary
```

## 💾 データのバックアップと移行

- **ローカル保存**: コレクションやデッキデータはすべてお使いのブラウザ内部の `IndexedDB`（データベース名: `MTGCollectionSummaryDB`）に保存されます。外部のサーバーへ送信されることは一切ありません。
- **JSONバックアップ**:
  1. ナビゲーションの「⚙️ 設定」を開きます。
  2. 「全データJSONバックアップ出力」をクリックすると、すべてのコレクション、デッキ、スナップショット、ウィッシュリストを含む完全なJSONファイルがダウンロードされます。
- **データの復元・引き継ぎ**:
  1. 別のPCやブラウザで本アプリを開きます。
  2. 「⚙️ 設定」の「JSONバックアップから復元」から保存したJSONファイルを選択します。
  3. 「既存データを上書き全置換」または「現在のデータにマージ」を選択して安全にデータを復元できます。

> [!WARNING]
> ブラウザの閲覧履歴・Cookie・サイトデータを一括削除すると IndexedDB の内容も削除される場合があります。定期的なJSONバックアップの保存を強く推奨します。

### Scryfall API 利用について
本ツールのカードデータおよび画像は、[Scryfall API](https://scryfall.com/docs/api) を利用して取得しています。
- Scryfallの定めるリクエスト頻度（1秒あたり5〜10リクエスト以内）を遵守するため、リクエストキューおよびデバウンス処理、IndexedDBによるローカルキャッシュを実装しています。
- 価格データは参考値であり、市場の最新相場と若干のタイムラグがある場合があります。
