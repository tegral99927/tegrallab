# MTGWanted（エムティージー・ウォンテッド）

**MTGWanted** は、Magic: The Gathering（MTG）の対戦相手募集画像を、19世紀アメリカ西部劇のヴィンテージ「WANTED（指名手配書）」スタイルで手軽に作成できるWebアプリケーションです。

Discord、Bluesky、X（旧Twitter）などのSNSタイムライン上で一目で伝わる、巨大なプレイヤーアイコンと対戦日時を兼ね備えた美しい募集ポスターを高解像度（16:9横長、正方形、縦長、長尺）で生成できます。

完全クライアントサイド（ブラウザ内）完結で動作し、サーバーへの画像送信やアカウント登録、外部APIへの依存はありません。

---

## 🌟 主な機能

1. **西部劇「WANTED」ポスターデザイン**
   - 羊皮紙の質感、経年染み、かすれ、木版印刷風の重厚な装飾枠。
   - 4つのオリジナルテーマ（Classic Wanted, Dark Outlaw, Red Bounty, Minimal Western）。
   - 4種の用紙テクスチャ（羊皮紙、粒子、粗挽きクラフト、スムースアンティーク）。
   - 4種の外枠スタイル（トリプル木版枠、オーナメント枠、ロープ調、シンプル二重枠）。

2. **大きなプレイヤーアイコン & 自由な調整**
   - PNG, JPEG, WebP形式のアイコン画像アップロード対応。
   - ブラウザ内でのズーム拡大縮小、上下左右パン位置微調整。
   - 丸型（円形）／四角型フレーム切り替え。
   - 古写真風セピア加工（ON/OFF & 強度スライダー調整）。
   - アイコン未設定時はオリジナルの西部劇カウボーイシルエットを自動描画。

3. **直感的な対戦日時候補管理**
   - 複数日時の追加・削除・並び替え（最大8件）。
   - 日付、開始時刻、終了時刻、自由追記メモ。
   - 日本時間（JST）の曜日自動算出（平日／土日判定）。
   - 3種類の日時表示形式（西部劇風装飾形式、日本語形式、英語形式）。
   - 「時間相談可」「終日OK」「いつでも歓迎」フラグ。

4. **対戦環境 & フォーマットの柔軟な選択**
   - 対戦環境: 紙（対面・店舗名入力欄付き）、紙（リモート・SpellTable等入力欄付き）、MTG Arena、Magic Online。
   - フォーマット: スタンダード、パイオニア、モダン、レガシー、ヴィンテージ、パウパー、コマンダー（EDH）、ブロール、ヒストリック、エクスプローラー、タイムレス、アルケミー、リミテッド、自由記述。

5. **募集要項メモ & テキストあふれ防止**
   - 初心者歓迎、カジュアル/競技、BO1/BO3、統率者ブラケット、VC可否などの自由記述。
   - よく使う文言をワンタップで挿入できるクイックタグ。
   - 自動改行、フォントサイズ自動縮小、情報量に応じた行間調整。
   - **文字の勝手な省略・削除は禁止**: 入力文字が多い場合、リアルタイムで警告を表示し、長尺ポスターへの切り替えや文章短縮を案内。

6. **募集ステータススタンプ**
   - 「募集中（スタンプなし）」
   - 「対戦相手決定（MATCH FOUND）」
   - 「募集終了（CLOSED）」
   - 決定・終了時はポスター上に斜めの掠れたヴィンテージラバースタンプを重ねて描画。

7. **画像比率 & 解像度最適化**
   - 標準横長: 1600 × 900 (16:9 / Discord・Bluesky最適)
   - 高解像度横長: 1920 × 1080 (16:9 FHD)
   - 正方形: 1200 × 1200 (1:1 / SNSプロフィール・投稿)
   - 縦長ポスター: 1200 × 1600 (3:4 / クラシック手配書比率)
   - 長尺ポスター: 1200 × 1900 (2:3+ / 情報量が多い募集用)

8. **高画質エクスポート & クリップボード直接コピー**
   - PNG（可逆圧縮・高画質） / JPEG（品質スライダー付き）出力。
   - クリップボードに画像を直接コピー（Discordのチャット欄にそのままCtrl+Vで貼り付け可能）。
   - ファイル名自動生成: `MTGWanted_YYYY-MM-DD.png`

9. **募集テンプレートプリセット**
   - アリーナランク対戦
   - アリーナカジュアル
   - コマンダー募集
   - 紙のリモート対戦
   - 店舗・対面対戦
   - フリー募集

10. **データ永続化 & プライバシー保護**
    - LocalStorageによる入力内容の自動保存と復元。
    - アバター画像は容量制限を超えないよう自動リサイズして安全に保存。
    - 設定のJSONファイルエクスポート & インポート。
    - 入力データ・画像は外部サーバーへ一切送信されず、完全にローカル動作。

## 🚀 起動方法

### ローカルでの直接起動
1. 本リポジトリまたは `tools/mtgwanted` フォルダを作業環境に配置します。
2. `tools/mtgwanted/index.html` を任意のWebブラウザ（Chrome, Edge, Firefox, Safari等）で開くだけで即座に使用できます。
3. ビルドツールやNode.js、npmパッケージのインストールは不要です。

### ローカルサーバー環境で動かす場合（推奨）
```bash
# Pythonの簡易サーバー
python -m http.server 8000
# http://localhost:8000/tools/mtgwanted/ にアクセス
```

## 🛠️ カスタマイズ方法

### BOOTH URL（開発者支援リンク）の設定
`tools/mtgwanted/js/storage.js` の先頭にある `CONFIG.BOOTH_URL` を編集してください。

```javascript
export const CONFIG = {
  APP_NAME: 'MTGWanted',
  VERSION: '1.0.0',
  BOOTH_URL: 'https://tegrallab.booth.pm/', // ご自身のBOOTHのURLを設定
  // ...
};
```
※空文字 `''` に設定すると、支援カード内のリンクは無効化されます。また支援カードは画像保存後にのみ控えめに表示され、ユーザーが閉じることも可能です。
