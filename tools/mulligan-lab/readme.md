# Mulligan Lab | MTG初期手札・マリガン分析ツール

Magic: The Gathering（MTG）の初期手札・ロンドンマリガンのトレーニングおよびデッキの安定性・再現性の統計的分析を行う静的Webアプリケーションです。

Scryfall APIと連携し、実際のカード画像を用いた直感的な手札トレーニング、超幾何分布に基づく理論値計算、Web Workersを活用した最大10万回の高速モンテカルロシミュレーションを提供します。

---

## 1. アプリケーションの概要

本ツールは「勝率」そのものではなく、プレイヤーがコントロール可能な**「初期手札の質」「マリガン判断」「キープ基準の厳格さ」「デッキの再現性」**の改善を目的として設計されています。

- **完全静的Webサイト**: React / Vue / Tailwind等のフレームワークやビルド工程（npm, Webpack等）を一切使用せず、Vanilla HTML5 / CSS3 / ES6+ JavaScript のみで動作します。
- **プライバシー保護**: ユーザー登録不要、サーバー送信なし。デッキデータや履歴はすべてブラウザ内（IndexedDB / LocalStorage）に安全に保存されます。
- **公式Scryfall API連携**: 日本語版カード画像・日本語カード名・オラクルテキストを標準対応。両面カード（DFC）や分割カードも適切に取得・キャッシュ。
- **カード画像言語切替**: ヘッダーのワンクリックボタン（🇯🇵 日本語 / 🇺🇸 EN）または設定画面から、日本語画像優先と英語画像の表示を瞬時に切り替え可能（日本語版が存在しない特殊カードは英語へ自動フォールバック）。

## 3. 主な機能

### 1. デッキ管理 (`Deck Management`)
- **多形式対応**: MTG Arena形式、MTGO形式、一般的なテキスト形式、日本語・英語カード名、セットコード・コレクター番号付き形式。
- **テキストファイルアップロード**: `.txt` や `.dec` のドラッグ＆ドロップ読込。
- **セクション自動分離**: メインデッキ、サイドボード、統率者、相棒を正しく分離。※初期手札の生成ライブラリーにはメインデッキのみを含めます。
- **未認識カードの手動修正**: 認識できなかった行を警告表示し、手動で修正・再検索可能。

### 2. マリガントレーニング (`Mulligan Training`)
- **ロンドン・マリガンの完全実装**: マリガンのたびに7枚を引き直し、キープ時に有償マリガン回数と同じ枚数のカードをライブラリーの一番下へ配置。
- **実カード画像の表示**: Scryfallの高画質アートワークを使用。ダブルクリックまたはズームボタンでオラクルテキストや両面カード（裏面）も確認可能。
- **操作性**: ドラッグ＆ドロップまたはタップによる手札並び替え、ボトム送りカードの選択順序（1, 2...）の強調表示。
- **ターン経過ドロー**: キープ後、第1ターン〜第5ターンまで実際にカードを引くシミュレーションが可能（先攻・後攻の初手ドロー有無を反映）。
- **通常モードとブラインドモード**: ヒント情報を伏せて自身の直感で判断し、確定後にキープ条件との一致・不一致のフィードバックを確認。
- **判断理由の記録**: 土地枚数、色マナ、初動、キーカード、相手アーキタイプ（アグロ、コントロール等）などを記録。

### 3. 初期手札分析 (`Opening Hand Analysis`)
- **超幾何分布（理論値）**: 土地0枚〜7枚の各確率、および累積確率（N枚以上引く確率）を数学的に正確に算出。
- **タグ別出現確率**: 初動、除去、キャントリップ、キーカード等を初手に引く確率を横棒グラフで可視化。
- **マナカーブ・色マナ供給**: デッキ全体の平均CMCおよびマナ総量分布、色マナ源の割合を表示。
- **ターン経過累積確率**: 先攻・後攻に応じた各ターンまでのキーカード・土地の獲得確率を折れ線グラフで算出。

### 4. キープ条件ビルダー & 自動マリガンシミュレーション (`Simulation`)
- **GUI条件ビルダー**: プログラミング知識不要で、AND / OR / NOT のネストされた条件グループを作成可能。
- **Web Workersによる非同期処理**: 1,000回〜100,000回のシミュレーションを実行中もブラウザUIが一切フリーズしません。
- **高度なボトム判定**: マリガン時に $(7 - N)$ 枚のすべての組み合わせを検証し、条件を満たす最適な最終手札が存在するかを判定。
- **統計出力**: 7枚キープ率、6枚キープ率、5枚キープ率、4枚以下キープ率、平均マリガン回数、平均キープ枚数、強制キープ率、95%信頼区間。

### 5. カード役割・タグ設定 (`Card Roles`)
- **初期プリセットタグ**: 土地、アンタップイン土地、タップイン土地、マナ加速、初動、ドロー、キャントリップ、サーチ、コンボパーツA/B/C、キーカード、フィニッシャー、除去、打ち消し、手札破壊、妨害対策、墓地対策、キープしたくないカード。
- **自動分類ヒューリスティクス**: カードタイプやオラクルテキストから初期タグ候補を自動提示（ユーザーが自由に編集可能）。
- **カスタムタグ**: ユーザー独自の役割タグをカラーパレット付きで追加・一括付与可能。

### 6. トレーニング履歴 & 復習モード (`History & Review`)
- 過去のトレーニングセッションの詳細手札、マリガン回数、ボトム送りカード、判断理由を一覧表示。
- **復習モード**: 過去の難しい手札を再読み込みし、改めてマリガン判断を練習可能。
- **CSVエクスポート**: Excel等の表計算ソフトで文字化けしないUTF-8 BOM付きCSVダウンロード。

### 7. デッキ比較機能 (`Deck Comparison`)
- 2つのデッキ（例: 土地22枚版 vs 土地24枚版）の初期手札キープ率や土地事故率をパーセントポイント（pp）で比較。

## 4. 起動方法

### ローカルでの実行
本ツールは静的HTML/CSS/JSで構成されているため、特別なビルドツールやNode.js環境は不要です。

ブラウザのセキュリティ制約（Web WorkersやFetch APIが `file://` プロトコルで制限される場合があります）を避けるため、ローカルWebサーバーでの起動を推奨します。

#### 例1: Pythonを使用する場合
```bash
cd tools/mulligan-lab
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。

#### 例2: VS Code Live Server を使用する場合
`index.html` を右クリックして「Open with Live Server」を選択します。

## 6. Scryfall APIの利用規約・遵守事項

- **レートリミット遵守**: Scryfall公式ガイドラインに基づき、リクエスト間に約100msのディレイを設けるリクエストキューを実装しています。
- **バッチ取得**: `/cards/collection` エンドポイントを活用し、最大75枚単位でまとめて取得することでAPIへの負荷を最小化しています。
- **IndexedDBキャッシュ**: 取得したカード情報はブラウザ内のIndexedDBに永続キャッシュされ、同一カードへの重複リクエストや大量シミュレーション中の通信は一切発生しません。
- **HTTP 429バックオフ**: レートリミット（429）を検知した場合は自動的にキューを一時停止し、バックオフ待機後に安全に再開します。

## 7. シミュレーションの計算方法と制約

### 超幾何分布（理論値）
初期手札7枚における各カードや土地の枚数確率は、非復元抽出モデルである超幾何分布の確率質量関数（PMF）を用いて厳密に計算しています。
$$P(X = k) = \frac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}$$
- $N$: デッキ総枚数
- $K$: デッキ内の対象カード（または土地）の総枚数
- $n$: 初期手札枚数（通常7枚）
- $k$: 手札に含まれる対象カードの枚数

階乗のオーバーフローを防止するため、対数ガンマ関数（対数階乗キャッシュ）を用いた安定した二項係数計算を行っています。

### モンテカルロ法
複数条件のAND/OR組み合わせや、ロンドンマリガンにおけるボトム送り判定は組み合わせ爆発を起こすため、疑似乱数生成器（Mulberry32）を用いたモンテカルロシミュレーションによって推定値を算出します。
乱数シードを指定することで、同一条件での再現性のあるシミュレーションが可能です。

### 注意事項
- **均等ランダムシャッフル**: 本ツールは数学的に純粋なFisher–Yatesシャッフルを前提としています。MTG ArenaのBO1（Best of 1）に存在する独自の初期手札補正アルゴリズムを公式に再現したものではありません。
- **勝率との相違**: 本ツールの「条件達成率」や「キープ率」はユーザーが設定した戦略基準に対する達成度であり、対戦における実際の勝率そのものを保証するものではありません。

## 8. テスト方法

`tests/index.html` にアクセスすることで、以下の項目に関する自動ユニットテストがブラウザ上で即座に実行されます。

1. デッキリスト解析（Arena、MTGO、日本語名、セットコード、重複集約）
2. ライブラリー展開とサイドボード等の正確な除外
3. Fisher-Yatesシャッフルの完全性とPRNGシード再現性
4. ロンドンマリガンおよび無料マリガンのボトム枚数計算
5. キープ条件ASTの評価（AND / OR / NOT、土地、タグ）
6. 超幾何分布理論値と全事象確率1.0の検証
7. バックアップデータおよびCSV出力フォーマットの検証
