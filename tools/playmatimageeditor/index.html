ヘルプ & プレイマット印刷入稿ガイド

キーボードショートカット

  • Ctrl + Z: 元に戻す (Undo)
  • Ctrl + Y / Ctrl + Shift + Z: やり直し (Redo)
  • Ctrl + S: プロジェクトを.playmat.jsonとして保存
  • Delete / Backspace: 選択したオブジェクトを削除
  • Space + ドラッグ: キャンバスのパン移動
  • マウスホイール: 拡大・縮小（ズーム）
  • Shift + 拡大縮小: アスペクト比（縦横比）を維持してリサイズ
  • Shift + 回転: 15度刻みでスナップ回転
  • Ctrl + V: クリップボードから画像を貼り付け

印刷ガイド線の意味

ピンク色の外枠（塗り足し領域）: 印刷後に断裁される余白です。この枠一杯まで背景画像を広げてください。

水色の線（仕上がり線）: 実際のプレイマット製品の外周ラインです。製造工程により数ミリの断裁ズレが発生します。

緑色の点線（セーフエリア）: 断裁ズレがあっても切れてはいけない重要文字やカード枠は、必ずこの内側に配置してください。
