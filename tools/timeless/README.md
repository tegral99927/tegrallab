# TimeLess（タイムレス）

**TimeLess** は、オンラインゲームやリモートカード対戦（Magic: The Gathering、Commander/統率者戦、MTG Arena、Magic Online等）におけるプレイヤーの活動可能時間を直感的に視覚化し、SNSやDiscord等で共有できる高品質な16:9画像をローカル環境完結で生成するWebツールです。

完全クライアントサイド動作のため、サーバーへのデータ送信やアカウント登録、Cookieは一切不要です。

---

## 🌟 主な機能

1. **ユーザープロフィール設定**
   - プレイヤー名、タイムゾーン、一言コメント
   - ローカル画像ファイル（PNG / JPEG / WebP）からのアイコン登録、円形トリミング＆ズーム調整
   - 未設定時のオリジナルデフォルトアバター生成

2. **直感的な週間スケジュール編集（7日×24時間）**
   - 月曜日〜日曜日の各曜日、0:00〜24:00（1時間単位・168セル）
   - マウスドラッグ＆タッチ操作による連続選択／解除（開始セルの反転動作を保持）
   - キーボードナビゲーション（矢印キー移動、Space/Enterトグル）
   - 平日・休日一括選択/解除、全選択/全解除
   - よく使う時間帯一括適用（朝 6-12、昼 12-18、夜 18-24、深夜 0-6）
   - 曜日ごとのスケジュール複製（コピー＆ペースト）
   - プリセットテンプレート（平日夜型、休日中心、深夜型、毎日自由設定）

3. **平日・休日の24時間リンググラフ早見表**
   - WEEKDAYS（月〜金・5日間）および WEEKENDS（土日・2日間）の2つの円環グラフ
   - **高度な集計ロジック**: 曜日間で単純合算するのではなく、各1時間区間について「対象曜日のうち何日で活動可能か」の選択日数率（0%〜100%）を算出し、不透明度とセグメントの厚みで可視化
   - グラフ中央に「1日あたりの平均活動可能時間」を表示

4. **対応プレイ環境 & フォーマット設定**
   - 紙・リモート（Paper / Remote）、Arena、Magic Onlineの各環境チェック
   - Standard、Modern、Pioneer、Legacy、Vintage、Pauper、Commander等の主要フォーマット複数選択
   - ユーザー独自のフォーマット自由追加

5. **補足メモ機能**
   - 最大300文字、改行対応（Discordアカウント、対戦条件、初心者歓迎等の連絡事項）
   - 空欄時は自動的に非表示となり、無駄な余白を削減

6. **16:9 高解像度画像出力（専用キャンバスレンダラー）**
   - 標準解像度: **2560×1440（2K）**
   - プリセット: 1920×1080 (FHD)、2400×1350 (SNS共有最適化)、3200×1800 (高精細)
   - 出力形式: PNG（可逆高画質）、JPEG（画質調整スライダー付き）
   - クリップボードへの直接画像コピー機能（DiscordへCtrl+Vでそのまま送信可能）

7. **5種のカラーテーマ**
   - Midnight Blue（標準ダーク）
   - Emerald（エメラルド）
   - Violet（バイオレット）
   - Monochrome（モノクローム）
   - Light Minimal（ライトミニマル）

8. **プライバシー & データ保存**
   - 入力データはIndexedDBおよびLocalStorageに完全自動保存（オフライン動作可能）
   - 設定のJSONファイルエクスポート & インポート（スキーマ検証・サニタイズ付き）

## 🚀 起動方法

### 静的ファイルとして実行
外部ビルドツールやNode.jsサーバーを必要としないため、Webサーバーでホスティングするか、ローカルのHTTPサーバーで即座に動作します。

例（Pythonの簡易サーバー）：
```bash
cd tools/timeless
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開いてください。

## 💡 利用方法

1. **プロフィールの入力**: プレイヤー名、タイムゾーン、コメントを入力し、必要に応じてアイコン画像をアップロードします。
2. **スケジュールの入力**: マウスのドラッグまたはタップ操作で活動可能な時間帯を塗りつぶします（テンプレートや一括ボタンを活用すると数秒で設定できます）。
3. **環境・フォーマットの選択**: 対戦可能な環境（紙、Arena等）とフォーマットにチェックを入れます。
4. **補足メモの入力**: 連絡先や注意事項を記入します。
5. **画像の保存**: 右側のプレビューを確認し、「画像をダウンロード」または「クリップボードに画像をコピー」をクリックしてDiscordやX（旧Twitter）に共有します。

---

## 🛡️ プライバシーとセキュリティ

- 入力したユーザー名、画像、メモなどのすべてのデータは、お使いのブラウザ内部（IndexedDB / LocalStorage）にのみ保存されます。
- 外部サーバーへの通信やデータ収集、Cookieの付与は一切行いません。
- 完全オフライン環境（インターネット切断時）でも全機能が動作します。
